# Milestone Interviews

A clean, question-by-question study record for every milestone's closing mock
interview — separate from `ROADMAP.md`, which documents the *process* (what was
built, what broke, what was decided) rather than a readable Q&A transcript. Use this
directory when reviewing for an actual interview; use `ROADMAP.md` for project history.

Each file follows the same shape: the question as asked, the answer as actually given
(including wrong or imprecise first attempts, since those are part of what to review),
any correction, and the accepted final answer.

**Fidelity note:** milestones 0.2 through 6.2 predate this conversation's own
transcript and are reconstructed from `ROADMAP.md`'s narrative summaries — accurate in
substance, but not verbatim. Milestones 6.3 onward were transcribed directly from a
live session transcript.
